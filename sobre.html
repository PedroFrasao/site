O que é o Mundo Animal?

O Mundo Animal é um site informativo criado como trabalho acadêmico para a disciplina de Desenvolvimento Web da Universidade de Uberaba (Uniube). O objetivo é apresentar curiosidades e informações sobre diferentes grupos de animais de forma simples e educativa.

Objetivos do Projeto

  1. Apresentar informações sobre diferentes grupos de animais
  2. Praticar a criação de páginas HTML e CSS
  3. Desenvolver habilidades de estruturação de conteúdo web
  4. Criar uma navegação clara e funcional
  5. Aplicar conceitos de formulários, tabelas e listas em HTML

O que você vai encontrar aqui

  • Informações sobre mamíferos, aves e répteis
  • Curiosidades sobre animais marinhos
  • Galeria de fotos dos animais
  • Tabelas comparativas com dados interessantes
  • Links para sites especializados
  • Formulário de contato
